# Contributing

Review PROJECT_STATUS.md and the candidate requirements before changing scope. Preserve stable IDs and evidence history. Keep internal instruction packages, credentials, raw datasets, customer records and generated environment directories out of Git. Use focused branches and commits; explain behavior/evidence changes and run `python scripts/check_repository.py`.

Douglas Moore is the sole maintainer. Self-review is not independent assessment. The offline verification workflow checks software and repository consistency on pushes and pull requests. This repository is public. Current branch-protection and required-check settings must be verified directly; the connected GitHub integration cannot read branch-protection settings. Scanning remains separate. Inspect actual workflow results before merging; local verification is not a remote CI pass. No license or third-party redistribution rights are granted by contributing instructions.
