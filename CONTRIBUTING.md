# Contributing

Review PROJECT_STATUS.md and the candidate requirements before changing scope. Preserve stable IDs and evidence history. Keep internal instruction packages, credentials, raw datasets, customer records and generated environment directories out of Git. Use focused branches and commits; explain behavior/evidence changes and run `python scripts/check_repository.py`.

Douglas Moore is the sole maintainer. Self-review is not independent assessment. The offline verification workflow checks software and repository consistency on pushes and pull requests. Branch protections and required-check enforcement remain unconfigured: GitHub reports a plan restriction for rulesets on this private repository, and the connected GitHub integration has no administration capability. Scanning remains separate. Inspect actual workflow results before merging; local verification is not a remote CI pass. No license or third-party redistribution rights are granted by contributing instructions.
