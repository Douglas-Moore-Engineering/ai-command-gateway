# Code walkthrough

Azure retirement was verified at **2026-10-16 05:13:03 UTC** in the established subscription ending `f609`. The subscription remains `Enabled`, with zero active resources, zero resource groups, zero project-principal role assignments and zero management locks; both existing subscription Owner assignments were preserved. Local datasets, downloaded evidence and source/GitHub copies remain retained. The Azure helpers below remain implementation source and historical pilot evidence; their fixed targets have been retired. The [retirement record](../governance/azure-retirement-v0.4.json) preserves verification and provider-recovery limits.

- [cli.py](../src/ai_command_gateway/cli.py) exposes `profile`, `qualify`, `catalog`, `advise`, `eval-advice`, `replay`, `demo`, `evaluate`, `approve`, `execute`, and `audit`, with strict request JSON parsing and explicit exit codes.
- [datasets.py](../src/ai_command_gateway/datasets.py) profiles the five external files, preserves provenance and independent source IDs, and treats archive contents as data.
- [qualification.py](../src/ai_command_gateway/qualification.py) verifies inventory identities, analyzes complete S1 numeric/timestamp columns and emits hashed aggregate evidence. It preserves timezone metadata, measures duplicate/order/cadence quality, and leaves engineering semantics unresolved.
- [evidence.py](../src/ai_command_gateway/evidence.py) transforms allowlisted aggregate profile values into typed facts, writes a catalog/snapshot/manifest bundle and regenerates that bundle during loading. [Evidence design](evidence-design.md) explains its consistency checks and authenticity limits.
- [advisor.py](../src/ai_command_gateway/advisor.py) retrieves exact catalog statements with source/file/field citations or abstains. Its response structure cannot carry a command proposal, and it has no gateway execution dependency.
- [model_advisor.py](../src/ai_command_gateway/model_advisor.py) adds the explicitly selected OpenAI adapter after local retrieval. `advise_with_model` creates a minimal structured-output request, supports a credential-free dry run, checks every returned ID and exact statement, and labels validated responses or offline fallback. It rechecks evidence after the provider returns and clears claims if the evidence changed. The provider cannot select new evidence, change policy or invoke the gateway.
- [openai_transport.py](../src/ai_command_gateway/openai_transport.py) supplies `OpenAIConfig` and a bounded HTTPS request to the fixed OpenAI endpoint. It reads the key only when sending, verifies TLS, rejects redirects/non-success responses, limits request/response bytes, makes no automatic retry and returns sanitized error codes.
- [answer_display.py](../src/ai_command_gateway/answer_display.py) renders cited sentences without JSON and saves identical output through `--output`. Terminal control characters are removed at display. In `--explain` mode the model adapter checks sentence shape, evidence IDs/coverage and numeric tokens, then attaches local citations. These checks do not prove semantic accuracy; generated prose is labeled for review. [ADR-005](../architecture/adr/ADR-005-cited-explanations.md) and [examples](answer-examples.md) distinguish model explanation, offline observations and simulated verification.
- [advice_evaluation.py](../src/ai_command_gateway/advice_evaluation.py) runs the frozen local casebook and verifies expected facts, exact statements, citation bindings, source filters and abstention without model inference.
- [gateway.py](../src/ai_command_gateway/gateway.py) reloads and validates policy, checks proposals/state, then atomically persists audit plus approval consumption in SQLite. It returns only mock receipts.
- [replay.py](../src/ai_command_gateway/replay.py) preserves historical S1 observations and unknown semantics while exercising the unqualified-policy gate.
- [azure_job.py](../src/ai_command_gateway/azure_job.py) wraps the finite workload for a manual Container Apps Job. Local demo mode needs no Azure SDK or credential. Cloud mode uses a user-assigned managed identity, verifies all five input identities before dataset analysis, uploads only declared artifacts and writes completion last. Separate UUID prefixes isolate overlapping runs; no distributed approval ledger or model call is introduced.
- [Dockerfile](../Dockerfile) packages the source on a digest-pinned Wolfi base with vendor-maintained Python 3.13, exact OS versions and hashed Linux wheel locks, then runs as UID/GID 10001. [.dockerignore](../.dockerignore) admits runtime code and controlled metadata/synthetic inputs only. The existing Windows Python 3.10 environment is separate historical local evidence.
- [infra/main.bicep](../infra/main.bicep) composes private networking/DNS, storage, registry, identity, monitoring, environment and the optional manual job. [Static-check dispositions](../infra/security-exceptions.md) preserve scoped exceptions and their remaining review work.
- [job-only.bicep](../infra/job-only.bicep) references existing foundation resources and deploys only the manual job. It prevents a job update from redeploying the VNet and removing separately created operator peerings.
- [azure_preflight.ps1](../scripts/azure_preflight.ps1) selects the foundation or isolated job template, compiles locally and contacts Azure only with `-Online`. [deploy_azure.ps1](../scripts/deploy_azure.ps1) applies only with explicit `-Online -Deploy`, successful what-if and `-AllowModify` when needed. Job-stage changes outside the manual job are always rejected. [test_azure_scripts.ps1](../scripts/test_azure_scripts.ps1) exercises these gates with an isolated fake Azure CLI.
- [azure_operator_transfer.py](../scripts/azure_operator_transfer.py) runs on the temporary private operator VM using its explicitly pinned identity. It validates private DNS, publishes the reviewed OCI bytes without rebuilding, creates and fully reads back five hash-bound inputs, downloads bounded declared run artifacts, and queries a fixed console table for one execution. Tokens and provider error bodies are not printed; partial log responses are rejected.
- [start_azure_pilot_test.ps1](../scripts/start_azure_pilot_test.ps1) records explicit ARM execution-start requests and reviewed execution-only overrides. Its start receipt is separate from eventual ARM completion. [probe_azure_job_identity.py](../scripts/probe_azure_job_identity.py) checks private DNS, fixed input reads, expected denied input writes and output write/read behavior under the job identity.
- [verify_azure_outputs.py](../scripts/verify_azure_outputs.py) checks downloaded completion manifests, UUID/mode/artifact allowlists, byte counts, hashes and declared result expectations. It does not execute SQLite or pickle content and does not infer Azure provenance or ARM success from local files. [remove_azure_operator.ps1](../scripts/remove_azure_operator.ps1) validates and removes only the approved temporary group and enumerated foundation children.
- [tests](../tests) exercise command boundaries, source identities/time quality, catalog integrity and excluded source instructions, cited retrieval/abstention, guarded model responses, provider failures, stale observations, approvals, replay and failure handling. Provider responses are simulated; these tests do not measure live model quality.
- [verify_local.py](../scripts/verify_local.py) reproduces tests, consistency checks and synthetic demo, optionally profiles/replays the supplied inputs, and records version/hash-bound evidence.
- [check_repository.py](../scripts/check_repository.py) validates local links, stable requirement IDs, traces and original discovery SHA-256. It excludes environments, caches and generated outputs and makes no network calls.

The deterministic core and advisor use the standard library; source analysis uses Arrow, NumPy, SciPy and HDF5 readers. Package versions are pinned in [requirements-dev.lock](../requirements-dev.lock). The optional provider transport uses the standard library, without an additional SDK. It makes no call unless explicitly selected and local evidence is available. The catalog draws from the aggregate profile; the separate qualification report adds timestamp evidence for review. Neither promotes observed extrema into operating limits. [Source semantics](source-semantics.md) records measured findings and remaining engineering questions; independent domain grounding still needs an approved corpus and reviewer evidence.

The v0.4 path is local retrieval, optional request preview or provider call, then exact-claim validation and local evidence revalidation. Provider output can contain all selected claims in any order or refuse; it cannot paraphrase them or broaden their meaning. The final response reconstructs original local claim objects in the validated order, preserving their text/citations. Missing configuration, transport failures and invalid responses preserve the offline result with a labeled status; changed evidence clears claims. See [ADR-003](../architecture/adr/ADR-003-guarded-model-advice.md) and the [provider instructions](demo.md#optional-openai-advice). This narrow contract verifies integration mechanics; ordering quality is unmeasured, and more useful generative explanation requires a separately reviewed grounding contract and representative quality evaluation.

The Azure path starts independently at `python -m ai_command_gateway.azure_job`. Its source/image fallback is synthetic `demo`; the historical Azure pilot explicitly set `dataset-analysis` before retirement. The image contains no raw datasets and the job makes no hosted-model calls. During the completed pilot on 2026-10-16 UTC, the reviewed image and all five inputs were transferred through private access; separate ARM records show successful demo/dataset executions with private console logs. [Azure implementation](azure-implementation.md) distinguishes those live records from local tests and the passed identity-probe, expected-failure and artifact checks, with temporary-access cleanup and the then-retained configuration verified before the later full-retirement request. Whole-infrastructure Checkov has an operator-links parser error and no applicable job-specific checks; [the operator plan](azure-private-access-plan.md) records that scope. No cloud result establishes engineering units, operating policy or independent domain acceptance.
