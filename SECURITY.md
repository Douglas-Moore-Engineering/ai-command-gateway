# Security

Report suspected vulnerabilities privately to info@dmesystems.global. Do not include credentials, equipment identifiers or restricted records in public issues. No response-time commitment or continuous support is implied.

This baseline contains discovery documentation and a local checker, with no plant or cloud integration. Future implementation requires documented trust boundaries, least privilege, versioned policy/corpus integrity, prompt-injection and bypass tests, approval freshness/replay controls and auditable failure handling. No controls or security scans are represented as verified merely by this policy.
